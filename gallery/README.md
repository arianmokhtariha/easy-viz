# Gallery

The complete visual guide to easy-viz: one notebook per plot function, each walking
through every option on the same fictional business. Every chart starts from a SQL
query whose result goes straight into one easy-viz call.

On GitHub the notebooks show static images; open them in Jupyter for the interactive
Plotly figures.

## Start here
- [Meet the data](meet_the_data.ipynb): Fernway, an online home-and-lifestyle
  retailer with a paid membership, and its seven tables.

## Plot notebooks
Each notebook follows the same path: the question the plot answers, the one-line
default, a tour of every option, realistic combinations, the limits, and an insight
story that uncovers one of the patterns hidden in the data.

| Function | Family | Notebook | What it reveals |
|---|---|---|---|

The first notebooks arrive with the first plot functions (see the
[roadmap](../ROADMAP.md)).

## How the gallery is made
- The data is generated by [`data/generate.py`](data/generate.py) from a fixed seed;
  [`data/INSIGHTS.md`](data/INSIGHTS.md) is the answer key to its hidden patterns.
- The notebooks are executed, and the README images exported, by
  [`scripts/build_gallery.py`](../scripts/build_gallery.py)
  ([how it works](../docs/architecture/scripts/build_gallery.md)).
- CI runs every notebook on each pull request, so an example that stops working
  fails the build.
